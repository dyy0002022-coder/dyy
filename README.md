# Hunger 源文件

下载此分支的 ZIP 并解压。在解压后的目录运行：

```sh
cat archives/Hunger-Blender-v7.zip.part-?? > Hunger-Blender-v7.zip
cat archives/Hunger-Original-USDZ.zip.part-?? > Hunger-Original-USDZ.zip
shasum -a 256 -c SHA256SUMS
```

解压 Blender 包，将工程和 overhead-animation.mp4 保留在同一文件夹。工程的 Hunger · Food models 场景包含四种可编辑食物模型。USDZ 包保存米饭、综合食物、糕点和汉堡原件。
